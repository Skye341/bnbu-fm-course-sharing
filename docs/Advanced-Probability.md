# Advanced Probability
以前的Advanced Probability讲的是Elementary Probability，现在有Probability Theory这门课之后AP就可以将一些高级的概率论了。
这门课是本科生和研究生一起上的（至少25年是这样的）研究生那边这门课叫 *Real Analysis and Probability*.
